# PII eval corpus for pii_eval.py. One utterance per line, written the way
# Whisper transcribes speech. Words inside [[...]] are PII; everything else is
# not. Labels are per whitespace-split word, same as bleep.py.
#
# Policy: PII = anything that identifies or contacts a specific private
# person: their name (first, last, nickname), phone, email, street address
# (number, street, unit, city/state/zip when part of the address), account /
# card / ID / license / passport / plate / IP / username numbers, date of
# birth. NOT PII: public figures, companies, products, places on their own,
# prices, times, quantities, flight numbers, generic dates, common nouns that
# happen to be names (bill, rose, will, mark).
#
# Lines after "## test" are held out and only checked at the end.
